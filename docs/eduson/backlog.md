# Eduson Kids — бэклог вне этапа 1

Найдено по ходу работ, в этап 1 не входит. Пункты, которые закрываются только с
появлением сервера, — в `stage4-deploy-backlog.md`.

- **Блокировка учётки не останавливает подбор пароля** (наследие KOTOKOD).
  В `apps/auth_app/services.py::login` (строки ~150–167) `locked_until` проверяется
  уже после `authenticate()`. Пока учётка заблокирована, верный пароль даёт 429,
  неверный — 401: по коду ответа видно, что пароль угадан, перебор продолжается.
  Лечение: найти учётку по email и проверить `locked_until` до `authenticate()`,
  а для заблокированной отвечать одинаково при любом пароле.

## Синхро-пересборки KOTOKOD несовместимы с данными Eduson (2026-10-18)

- «rebuild-counters» ставит `lessons_done := Σ посещений` — сотрёт «пройдено до учёта» (N) у групп Eduson.
- «rebuild-planned-lessons» / `backfill_planned_lessons` (`generate_from_facts`) игнорируют
  `Group.lesson_number_offset` — перенумеруют план, health даст `number_mismatch`. Дефект KOTOKOD,
  задевает и его группы-продолжения.
- «rebuild-renewals» удаляет все сделки и пересобирает по посещаемости — сотрёт стадии, перенесённые из Eduson.
- `resize_plan` при сокращении курса не учитывает offset (граница `seq > total/step`).
Лечение: научить пересборки offset'у (и предохранитель в UI «Синхро»), до тех пор — не запускать.

## Команда import_eduson на Windows

Без `PYTHONUTF8=1` вывод «→» падает в консоли cp1251 (транзакция откатывается). Заменить символ или
форсировать UTF-8 в выводе команды.
