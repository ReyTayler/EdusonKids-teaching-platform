## Не запускать на данных Eduson

Синхро «rebuild-counters» (сотрёт «пройдено до учёта»), «rebuild-planned-lessons» / `backfill_planned_lessons`
(игнорируют offset — перенумеруют), «rebuild-renewals» (сотрёт стадии из Eduson). См. `docs/eduson/backlog.md`.

## Замечание по запуску на Windows

Консоль cp1251 не печатает «→» — запускать с `PYTHONUTF8=1` (без него команда падает на выводе и
откатывает транзакцию).
